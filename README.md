# 🎓 Student Management System

A web-based Student Management System built with Python Flask and PostgreSQL.

## 🌐 Live Demo
👉 [https://student-management-system-python.onrender.com](https://student-management-system-python.onrender.com)

## ✨ Features
- 🔐 User Authentication (Register/Login)
- ➕ Add, Edit, Delete Students
- 📊 Analytics & Charts
- 🔍 Search Students
- ⬇️ Export to CSV & Excel
- 🌙 Dark/Light Mode

## 🛠️ Tech Stack
- **Backend:** Python, Flask
- **Database:** PostgreSQL
- **Frontend:** HTML, CSS, JavaScript
- **Deployment:** Render
