# 🎓 Student Management System

A command-line based Student Management System built with **Python** and **JSON** file storage — designed with clean architecture using Models and Services layers.

---
## 📋 Live Demo

> 💡 This is a command-line Python project — not deployed on web.

## ▶️ Run Locally

```bash
git clone https://github.com/Bushra3895/student-management-system-python
cd student-management-system-python
python main.py
```

## 📋 Features

- ✅ Add new students
- ✅ View all students
- ✅ Update student information
- ✅ Delete students
- ✅ Data stored in JSON file (no database required)

---

## 🛠️ Technologies Used

- **Language:** Python 3.x
- **Storage:** JSON file (`data/students.json`)
- **Architecture:** MVC-inspired (Models + Services)

---

## 📁 Project Structure

```
student_management_system/
│
├── data/
│   └── students.json         # Student data storage
│
├── models/
│   └── student.py            # Student model/class
│
├── services/
│   └── student_service.py    # Business logic
│
├── main.py                   # Entry point
├── requirements.txt          # Dependencies
└── README.md
```

---

## 🚀 How to Run

**1. Clone the repository:**
```bash
git clone https://github.com/Bushra3895/student-management-system-python.git
cd student-management-system-python
```

**2. Install dependencies:**
```bash
pip install -r requirements.txt
```

**3. Run the program:**
```bash
python main.py
```
